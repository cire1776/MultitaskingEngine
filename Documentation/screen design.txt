## 🔍 Based on Where You Are Now (Terminal View @ 111x35)

You have:

### 1. **Execution Context (EC) View**
- Occupies the **entire right side** of the screen **under the status bar**
- Shows current tick (execution cycle), step (within that cycle), active streams, etc.

### 2. **Status Bar**
- Occupies the top line of the screen
- Displays tick, execution state, possibly step count, flow, etc.

### 3. **Output Column**
- Must be **adjacent to both history and source**, depending on which is focused
- Behaves like a Swift Playground output: contextual, step-specific, real-time

### 4. **History View**
- Scrollable, vertical listing of past execution steps
- Grouped by ULang op within a tick
- **Tick** is a complete cycle; steps cannot span ticks
- **Single tick header** is displayed at the top, with a **visual marker** at each tick boundary (no repetition)
- ULang ops are anchors for execution events

### 5. **Source Pane (Focused)**
- Replaces the former lint pane when active
- Displays the original ULang source comprehension, **one op per line**
- Uses a **hamburger menu icon** (☰) to represent the source view selector (instead of a document emoji, which is reserved for paging)
- **Four-digit line numbers** are shown to the left of each line (e.g., `0001`)
- **Next Lint View is omitted** here (no lint annotations)
- Each ULang op visually aligns with its corresponding output during execution, **even if output spans multiple lines**
- The pane is intentionally shorter than the history pane to reflect its structural rather than temporal nature
